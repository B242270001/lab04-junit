## 3. Мутаци тестийн тайлан (mvn-test-mutant.txt)
GradeCalculator.java классын score >= 90.0 нөхцөлийг зориуд score > 90.0 болгож мутаци үүсгэхэд дараах 2 тест дээр BUILD FAILURE (Failures: 2) гарч унасан:

ninetyIsExactlyA()

letterGradeBoundaries() parameterized тестийн 90.0 утгатай мөр.

Энэ нь миний бичсэн тест хязгаарын утгыг (90) үнэхээр барьж авч, алдааг илрүүлж чадаж байгааг баталж байна. Мутацийг засаж хэвийн болгосны дараа mvn test дахин ажиллуулахад бүх 30 шалгалт амжилттай (BUILD SUCCESS) болсон.

## 4. Хийсэн ажлын дүгнэлт
Энэхүү лабораторийн ажлаар орчин үеийн JUnit 5 болон Maven хэрэгслийг ашиглан нэгжийн тест бичих практик ур чадварыг эзэмшлээ. Тест бичихдээ Arrange-Act-Assert (AAA) бүтцийг чанд баримталсан бөгөөд @DisplayName ашиглаж тестийн үр дүнг хүнд уншигдахуйц ойлгомжтой болгосон. Кодын алдаа ихэвчлэн 89.99 эсвэл 90.0 зэрэг хязгаарын утгууд дээр гардаг тул эдгээрийг тусгайлан шалгах нь программын найдвартай байдлыг сайжруулдгийг харлаа. Мөн @ParameterizedTest болон @CsvSource-ийг ашигласнаар ижил төстэй олон тестийг давхардалгүйгээр, маш цэвэрхэн зохион байгуулах боломжтойг сурч авлаа. Эцэст нь, кодондоо зориуд алдаа оруулж (мутаци) унагаж үзсэнээр миний бичсэн тестүүд алдааг бодитоор барьж чадаж байгаа эсэхийг баталгаажуулсан нь хамгийн сонирхолтой туршлага байв.
